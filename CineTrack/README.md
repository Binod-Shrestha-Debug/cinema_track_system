# 🎬 CineTrack — Advanced Cinema Analytics System

CineTrack is a database project developed using PostgreSQL 18. It focuses on managing cinema operations, including movies, showtimes, customers, bookings, tickets, payments, and reviews.

The main goal of this project is to use SQL to organize data, solve practical business problems, and discover useful insights from cinema operations.

## 🎯 Project Objectives

- Design and manage a well-structured relational database.
- Store information about movies, cinemas, screens, and seats.
- Manage customer bookings, tickets, and payments.
- Analyze movie performance and cinema revenue.
- Understand customer booking and spending patterns.
- Improve database performance using advanced SQL techniques.

## 🛠️ Technologies Used

- PostgreSQL 18
- SQL
- PL/pgSQL
- pgAdmin 4
- Git and GitHub

## 📂 Project Structure

The project is organized into two main folders:

- `database/` — Database creation, tables, functions, triggers, sample data, and indexes.
- `queries/` — SQL queries for analysis, reporting, and performance optimization.

## 📊 Business Analysis

This project explores questions such as:

- Which movies generate the highest ticket revenue?
- Which cinema performs best in terms of revenue?
- Who are the most valuable customers?
- Which movie genres attract the most ticket sales?
- What percentage of bookings are confirmed, pending, or cancelled?
- Which movie receives the highest customer ratings?

## 🚀 How to Run the Project

1. Create the `cinetrack` database using the first SQL file.
2. Connect to the database using pgAdmin 4.
3. Execute the database scripts in numerical order.
4. Run the SQL query files to explore the data.
5. Review the business analysis and query execution plans.

**Note:** Run the sample data script only once on a fresh database.
